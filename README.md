Author: Dilnur Satibaldiyev

DevOps midterm project: Spring Boot Student CRUD API with PostgreSQL, Git, Docker Compose and Jenkins.

## Requirements
Java 17, Gradle 8.10.x, Docker Compose V2 and Jenkins (for the CI demonstration).

## Local development
```bash
gradle clean test
gradle bootRun
```

In local mode the API uses an in-memory H2 database. API endpoint: http://localhost:8080/api/students.
